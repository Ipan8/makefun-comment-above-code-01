**// This function was 12 lines. The agent 'cleaned it up' to 400. It now runs the whole company. Do not refactor.** (112 characters)

Run `node main.ts` to write the single line to `/output/entry.txt`.

The joke works because it is a warning, not a wisecrack: a 12-line helper got "cleaned up" by an agent into 400 lines, and somewhere along the way it became the thing the whole company runs on. Nobody understands it, nobody is allowed to touch it, and the comment is the only thing standing between the codebase and the next person who thinks they can tidy it up. Every developer has met a function like this — and obeyed its warning.
